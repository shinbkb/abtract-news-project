# Streamlit Community Cloud

Repository: shinbkb/abtract-news-project
Branch: main
Main file: app.py
Python: 3.12 (Advanced settings)

Source and runtime artifacts model.pt / retrieval_index.pt must be committed.
Do not deploy data CSVs, secrets, or a ZIP in place of the extracted source.
Dependencies use the official PyTorch CPU wheel index.

Open https://share.streamlit.io/, sign in, Create app, select the repository,
main branch and app.py, then Deploy. No secrets are required for inference.
The model has 13 classes and the retrieval index has 4,550 train articles.
